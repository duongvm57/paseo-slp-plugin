One file per durable decision, named `YYYY-MM-DD-<slug>.md`. There is no index.
After `Accepted`, only the `Status` line may change; to change the decision,
write a new file with `Supersedes:`. Aim for 10–25 lines. Do not copy agent
IDs, workspace IDs, machine paths or sensitive content.

## Context

What forced the decision, in a few sentences.

## Decision
