What the plugin actually doesPlugin thực sự làm gì

The methodology, the mechanism and the host each own different things.Methodology, mechanism và host có trách nhiệm khác nhau.

Read the mechanismĐọc mechanism

Paseo SLP turns an agent organization into two things at once: delivered role instructions and a durable, guarded work desk. A Supervisor observes governance; a Lead owns framing, coordination and technical acceptance; a Peer owns one bounded outcome. Paseo itself still owns agent processes, parentage, workspaces and messaging — the plugin does not install its own scheduler.Paseo SLP biến một tổ chức agent thành hai thứ cùng lúc: role instruction được nạp vào session và một work desk bền vững có gác cổng. Supervisor quan sát governance; Lead sở hữu framing, điều phối và technical acceptance; Peer sở hữu một outcome giới hạn. Paseo vẫn sở hữu tiến trình agent, parentage, workspace và messaging — plugin không cài scheduler riêng.

On the managed path, membership, assignment custody, scope declarations, task attempts, effect admissions and observed receipts live in a repository ledger that code checks when a tool is called. Human authority, the right problem, adequate review, meaningful proof and project acceptance remain decisions — a stored grant reference is a pointer, not authenticated permission.Trên managed path, membership, quyền giữ assignment, khai báo scope, task attempt, effect admission và receipt đã observe nằm trong ledger của repository mà code kiểm khi tool được gọi. Quyền Human, vấn đề đúng, review đủ, proof có ý nghĩa và nghiệm thu project vẫn là quyết định — grant reference đã lưu là pointer, không phải permission đã xác thực.

Tool surface: 29 visible desk tools (30 catalog rows — slp_desk_internal stays hidden); slp_desk itself is the MCP server config key, not a tool.Bề mặt tool: 29 desk tool hiển thị (30 dòng catalog — slp_desk_internal ẩn); slp_desk là config key của MCP server, không phải tool.
Why this shape existsVì sao hình dáng này
  • Authority gradient — a parent presenting the answer gets agreement, not premise checks.Authority gradient — parent đưa sẵn đáp án sẽ nhận đồng thuận, không phải kiểm chứng premise.
  • Perfect-plan trap — pre-selected files/APIs turn the worker into a typing bot.Perfect-plan trap — file/API chọn sẵn biến worker thành máy đánh chữ.
  • Unsafe parallelism — two agents on one checkout overwrite each other; an agent ID is not filesystem isolation.Song song không an toàn — hai agent trên một checkout ghi đè nhau; agent ID không phải filesystem isolation.
  • Biased or stale review — inheriting the author’s framing approves a candidate that no longer exists.Review thiên lệch hoặc cũ — kế thừa framing của tác giả sẽ duyệt candidate không còn tồn tại.
  • False completion — “done”, idle and green tests are attention signals, not proof.Hoàn thành giả — “done”, idle và test xanh là tín hiệu chú ý, không phải chứng minh.

The control-plane operationsCác operation control-plane
  • status / local-target / catalog — read-only views, computed when asked.status / local-target / catalog — view chỉ đọc, tính khi được hỏi.
  • activate — previews then journals the intent before any effect; materializes slp-runtime/<sha> immutably; publishes launchers and owned config entries.activate — preview rồi journal intent trước mọi effect; materialize slp-runtime/<sha> bất biến; publish launcher và config entry sở hữu.
  • reconcile — inspect divergence, complete an interrupted operation, or restore-before; foreign drift is reported, never overwritten.reconcile — inspect divergence, hoàn tất operation bị gián đoạn, hoặc restore-before; drift ngoài được báo cáo, không ghi đè.
  • deactivate — detaches owned provider/profile entries but retains runtime files for live sessions.deactivate — gỡ provider/profile entry sở hữu nhưng giữ file runtime cho session còn sống.

Every mutation is journaled before execution: an interrupted activate leaves a resumable intent, not silent drift. One writer holds the daemon home at a time — concurrent operations get BUSY.Mọi mutation được journal trước khi thực thi: activate bị gián đoạn để lại intent resume được, không drift âm thầm. Một writer giữ daemon home mỗi lúc — operation đồng thời nhận BUSY.

Why rebind only reaches the futureVì sao rebind chỉ chạm tương lai

A binding pins the runtime root, the Node binary, the family transport and the daemon home. Role hooks load that exact candidate — editing working files never hot-swaps a seat that already launched. Deactivation removes owned configuration but retains payload bytes for the same reason.Binding ghim runtime root, binary Node, transport của family và daemon home. Role hook nạp đúng candidate đó — sửa file đang làm không hot-swap seat đã launch. Deactivation gỡ config sở hữu nhưng giữ byte payload vì lý do đó.

How writing worksCách ghi hoạt động

Every mutation is a compare-and-swap transaction: the caller supplies expected revisions, the decide validates actor, pins and semantics under one lock, and the committed row is append-only history. Exact retries return the original receipt; a changed body under the same request id conflicts.Mọi mutation là transaction compare-and-swap: caller cung cấp revision mong đợi, decide validate actor, pin và semantics dưới một khóa, và dòng commit là history append-only. Retry y hệt trả về receipt gốc; body đổi dưới cùng request id gây conflict.

Historical refinements resolve ownership at each row’s own event time, while current commands check the present custody tuple. Registration never rewrites — planned succession adds revisions on the same assignment identity.Refinement lịch sử resolve ownership theo event time của từng dòng, trong khi lệnh hiện tại check tuple custody hiện tại. Đăng ký không bao giờ viết lại — kế nhiệm có chuẩn bị thêm revision trên cùng assignment identity.

Bounded by designGiới hạn theo thiết kế

Admission reserves remaining requests, records, membership slots, scope transitions and serialized bytes across the supported continuation — post-state capacity accounting funds the remaining supported edges across all ledger writers. Ordinary writes cannot spend reserved credits; the desk does not prune referenced proof or promise an unlimited queue.Admission reserve request, record, membership slot, scope transition và byte serialized còn lại trên đường continuation được hỗ trợ — capacity accounting sau trạng thái cấp kinh phí cho các edge còn hỗ trợ trên mọi ledger writer. Ghi thường không tiêu credit đã reserve; desk không prune proof được tham chiếu hay hứa queue vô hạn.

Why intent precedes effectVì sao intent đi trước effect

Admission writes the pending intent and its controls synchronously before the adapter calls out. If the process dies between “issued” and “observed”, the intent is durable evidence — not silent drift — and the obligation stays open until measured.Admission ghi intent pending và control của nó đồng bộ trước khi adapter gọi ra. Nếu tiến trình chết giữa “issued” và “observed”, intent là bằng chứng durable — không phải drift âm thầm — và nghĩa vụ vẫn mở cho tới khi đo được.

An exact historical request replays its recorded result with zero new effects; a changed body under the same id conflicts. Fresh reconciliation must measure the original positive identity — a missing listing, idle status or turn end alone releases nothing.Request lịch sử y hệt replay result đã ghi với không effect mới; body đổi dưới cùng id gây conflict. Reconcile mới phải đo positive identity gốc — listing thiếu, idle hay turn end riêng lẻ không giải phóng gì.

  • Lost — keep the original identity and resource obligations; reconcile by positive identity; unknown stays unknown.Mất — giữ identity gốc và nghĩa vụ resource; reconcile bằng positive identity; unknown vẫn unknown.
  • Denied — insufficient identity, revision, ownership or proof means perform:false and zero external effect.Bị từ chối — identity, revision, ownership hay proof không đủ nghĩa là perform:false và không effect ngoài.

Offer → acceptOffer → accept

The current owner appends an offer binding one exact live Lead membership at an ownership revision — the nominee joins nothing by receiving it.
