# Product Sense

## Who this is for

Operators running multi-agent engineering teams on Paseo — the Human holds
task authority; Supervisor/Lead/Peer roles implement delegation, judgment,
and evidence-based acceptance.

## What "good" looks like

- A cold agent session becomes productive from `AGENTS.md` + `./init.sh` alone
- Every mutation claim arrives with replayable evidence, not narrative
- Policy is enforced mechanically (doctrine pins, payload compare), not by
  reviewer vigilance

## What this repo is NOT

- Not an agent runtime — it is a *policy package* installed into Paseo
- Not a task database — `feature_list.json` tracks session scope; durable
  planning lives in `docs/exec-plans/`; orchestration state lives in Paseo
- Not a config dump — `docs/contract.md` owns file-level responsibility
