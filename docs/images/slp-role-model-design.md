# README overview

Both READMEs use `slp-overview.svg`, generated by
`scripts/generate-readme-diagrams.mjs`. Labels use English so the public docs
keep one diagram source and one checked asset.

The top row establishes Human intent and final acceptance alongside Paseo's
agent lifecycle. The execution area groups the Lead and illustrative Peer
dispositions. A separate optional Supervisor area shows workflow observation;
it does not imply implementation or project acceptance authority.

The repository desk occupies its own row. Its six cards show durable work,
review and evidence alongside planned owner handoff. They describe recorded
state and checks, rather than a mandatory six-step workflow. The lower row
shows session-entry instructions, checked preparation and explicit optional
configuration.

Blue marks execution and declared scopes, violet marks observation and
handoff, amber marks independent review, green marks candidate/check evidence,
and teal marks durable accounts. CSS variables provide light and dark palettes.
The SVG carries an accessible title and description; labels remain selectable
text. Update the generator, regenerate, and run it with `--check` to verify
that the published asset matches its source.
