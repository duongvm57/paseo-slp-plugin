# Design

Entry point for design reasoning. Detailed documents live in `docs/design-docs/`.

- `docs/design-docs/index.md` — status index (Accepted / Proposed / Deprecated)
- `docs/design-docs/core-beliefs.md` — the beliefs every design must preserve

Repo-level docs that already carry design weight (kept, not duplicated):

- `docs/contract.md` — candidate contract + file ownership + authority model
- `docs/architecture.md` — component architecture
- `docs/spec/` — specifications
- `docs/review-checklist.md` — review gates as practiced

Rule: a decision that changes authority, delegation, evidence, or payload shape
gets a `docs/design-docs/<slug>.md` entry and a status row in the index.
